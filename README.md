# ピックルボール ドリル集

練習会で使うピックルボールのドリル（練習メニュー）をまとめたサイトです。

- 公開URL: https://takumon.github.io/pickleball-drills/
- 構成: [Astro](https://astro.build/) + [Starlight](https://starlight.astro.build/)、GitHub Pages にデプロイ

## 開発

```sh
nvm use        # .nvmrc の Node.js を使用
npm install
npm run dev    # http://localhost:4321/pickleball-drills/
npm run build
```

`main` ブランチへの push で GitHub Actions が自動デプロイします。
