# コート図とアニメーションの約束

値（色、線の太さ、高さの段階など）は `src/config/court.ts` にある。ここには、なぜそう描くかを書く。

## 視点と人

- コートを真上から見た図にし、下側を自分たち（練習役）の側にする。自分の側から相手を見る向きが練習中の感覚に合うため。
- 人は全員右利きとして描き、特に断りがなければフォア側で打つ練習として描く。
- 腕は細い線、パドルは太い線で、体から斜め前に開くように描く。
- サーブ・リターン・3rdショットを打つ人は、ベースラインの後ろに置く。実際にそこから打つため。
- トランは「エリア」ではなく、キッチンラインとベースラインの中間の「位置」として扱う。トランに人がいる図は、位置関係が分かるようにベースラインまで描く。

## 打球の線

- コートは、ライトでもダークでも濃い緑の面に白い線で描く（実物のコートに近く、白い線や黄色のボールが見やすい）。
- コートの外まわり（ベースラインの後ろなど）も、少し濃い緑の地面として塗る。人がコートの外に立っても、ページの背景に溶けないようにするため（ライトでは白い丸の練習役が見えなくなった）。
- 色を使うのは、図の主役の「ボール」と「打球」だけにする。ボールは黄色で、穴のあいたピックルボールとして描く（実物のボールの色。ここだけは変えない）。打球の線は水色。水色は、濃い緑のコート、白い線、黄色のボールのどれとも見分けやすい。
- 人には色を付けない。練習役（自分）だけ白い丸、ほかの人は濃い丸にして、明るさの差で「自分はどれか」が一目で分かるようにする。誰がどの役かは丸の中の A・B と、図の下の「A 球出し役　B 練習役」で伝える。役ごとに色を変えると、見る人が色の意味を覚える必要があり、主役の打球が目立たなくなるため。
- 上から見た図の打球の線はまっすぐに描く（真上から見るとボールの通り道はほぼまっすぐ。高さは横から見た帯で見せる）。線の太さ・形・アニメーションの速さは打球の種類で変える。速く強い球は太い実線、柔らかく落とす球は細い点線、ロブは破線にする。
- 線の名前（ドロップ、ボレーなど）は線の上に書く。色の凡例で説明すると、図と凡例を見比べる手間がかかるため。
- タイトルの下にはIDやカテゴリのようなメタ情報を出さない（「詳細」に入れる）。

## アニメーション

- 手が2つ以上ある図は、アニメーションだけで見せる。コマ割りで並べると、スマホでは1コマが小さくなりすぎるため。
- 各手の終わりに、ボールは届いた位置（受ける人のパドル、または着地点）に残し、次の手はそこから始める。ボールの受け渡しのつながりを見せるため。
- コートの図のボールは打つ人と受ける人のパドルの位置を通る。
- 「視差効果を減らす」設定の端末では自動で再生せず、手を1つずつ切り替えて見せる。

## 高さとバウンド

- 高さは図の右に添えた淡い帯「横から見た高さ」で見せる。同じ場面を横から見た図で、縦の位置はコートとそろえ、右ほど高い。人とパドルの高さも描く。
- 帯は補助の情報なので、細く淡く描き、主役のコートの図と見た目で差をつける。
- 帯の地面には、横から見たコート（コートとキッチンの色の帯、ベースラインとキッチンラインの印）と柵を描き、上から見た図と位置を対応させる。柵の高さは仮に1ft（30cmほど）で描いている。
- 高さは10段階（地面、腰の下、白帯のちょい下、ネットの白帯、白帯のちょい上、腰上〜肩下、肩より上・頭付近、白帯から上、頭より上、かなり上）で決める。打つ高さと山の高さは打球の種類で決め、受ける高さは受けた人が次に打つ球の打点にする。
- ボールが弾む位置には黄色い輪を出す。横から見た高さの帯でも、同じ瞬間に地面の線の上に同じ輪を出す。2つの図が同じバウンドを表していると分かるようにするため（2つの輪を点線で結ぶ案は、なくても分かるのでやめた）。輪のない球はノーバウンドで打つ。ノーバウンドで取るかどうかが、ドリルの中身を左右するため。

## 柵

- ドロップ系の練習では相手のキッチンにL字の柵を置き、柵に当てずに内側へ落とす。柵はサイドラインから40cm、キッチンラインからパドル1本分の位置に置く。
- クロスのドロップは柵の角をねらう。
- 柵は補助のものなので、灰色の細い横木と支柱で描く。支柱の形で、打球の線やコートの線と見分ける。
