# まだ作っていないもの

合意済みで、まだ作っていないもの。作るときはここから始め、作ったら [decisions.md](decisions.md) に移す。

## メニュー表示の残り

- メニュー表示の一番下に、小さく「このメニューを編集」を置く（ビルダーを作るときに足す）。

## ビルダー（`/builder/`、PC向け）

- メニューを最初から作る。
- できること：カテゴリで絞り込み、名前で探してドリルを足す／ドラッグで並べ替える／見出し・休憩・自由記述を入れる／分数とセット数を入れる（標準時間が初期値）／練習全体の時間を入れると、残りと超過を出す／今あるメニューのURLを読み込んで直す／URLをコピーし、表示を確かめる。
- 保存の機能は作らない（URLが保存の代わりになる）。作業中の内容だけはブラウザを閉じても消えないようにする。
- チャットに投稿する文章（今の投稿に近い形）とURLを、まとめてコピーできるようにする。
- 画面の部品には Preact を使う（ビルダーだけ）。
- ビルダーへのリンクは控えめにする：クエリなしのトップページの一番下に小さく「メニューを作る」、メニュー表示の一番下に「このメニューを編集」の2か所だけ。
