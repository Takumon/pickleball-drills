---
title: 半面・強めの斜めディンクをボレーディンク
description: 半面で強めの斜めのディンクをボレーディンクで斜めに受け流し、そのままラリーする
sidebar:
  order: 1
drill:
  id: 4th001
  category: 4th
  subCategories: [vdk]
  aliases:
    - 4thで浮かせない
  scene: リターンを打ってキッチンへ詰めたところに、サーブ側の3rdショットが強めのクロスドロップで足元に沈んでくる。サーブ側はそれを見越して、打った人か逆サイドの人がキッチンまで走って上がってくる（シェイク&ベイク）。
  purpose: 奥へ無理に返さず、ボレーディンクでクロスに低く返して、詰めてきた相手にスマッシュさせない。浮かせるとスマッシュで決められるので、ここは守る。
  focus: 半面の中で斜めに打ち合い、面を作って当てる感覚と、打ったら基本の位置へ戻る動きを身につける。
  setup: 2人1組でコートの縦半分（半面）を使う。球出し役はサイドライン寄り、練習役は半面の真ん中で、どちらもキッチンライン付近に立つ。フォアハンド同士で打ち合うので、球は半面の中を斜めに行き来する。1面で2組同時にできる。
  feed: 球出し役は手元で一度弾ませてから、キッチンから半面の斜めに強めのディンクを出す。
  steps:
    - 来た球は全てボレーディンクで返し、そのままラリーを続ける
    - 一定時間で球出し役と練習役を交代する
  points:
    - 振らずに面を作って当てるだけ。相手のボールの勢いを使う
    - 返球は相手が打つところで低くなるように、相手の足元へ沈める
    - 体の正面で取らず、パドルを前に出して早めに捉える
    - 返したら必ず基本の位置へ戻る。最初から端で待たない
  diagram:
    rally: 2
    players:
      - { id: A, at: far-leftSide-kitchen, role: feed }
      - { id: B, at: near-left-kitchen, sidestep: near-leftCenter-kitchen, role: practice }
    shots:
      - { from: A, to: B, type: dink, n: 1 }
      # ラリーなので、ボレーディンクは A の手前に落とし、A がそれをディンクで返す
      - { from: B, to: A, type: volleyDink, n: 2, bounce: front }
    zones: [left]
  builderDefault:
    min: 2
    sets: 5
