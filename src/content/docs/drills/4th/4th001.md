---
title: 半面・強めの斜めディンクをノーバウンドボレー
description: 半面で強めの斜めのディンクをノーバウンドボレーで斜めに受け流し、そのままラリーする
sidebar:
  order: 1
drill:
  id: 4th001
  category: 4th
  aliases:
    - 4thで浮かせない
  purpose: 強めの球が足元に沈んできたとき、バウンドさせてから打つと球が浮きやすい。ノーバウンドで斜めに受け流すのは、4thで浮かせずに早いタイミングで返し、相手に5thで攻めさせないため。
  setup: 2人1組でコートの縦半分（半面）を使う。球出し役はサイドライン寄り、練習役はセンターライン寄りで、どちらもキッチンライン付近に立つ。フォアハンド同士で打ち合うので、球は半面の中を斜めに行き来する。1面で2組同時にできる。
  feed: 球出し役は手元で一度弾ませてから、キッチンから半面の斜めに強めのディンクを出す。
  steps:
    - 練習役はキッチンライン付近で、パドルを体の前に構えて待つ
    - 来た球を全てノーバウンドボレーで斜めに返す
    - そのままラリーを続ける
    - 一定時間で球出し役と練習役を交代する
  points:
    - 振らずに面を作って当てるだけ。相手のボールの勢いを使う
    - 返球はネットより低く、相手の足元へ沈める
    - 体の正面で取らず、パドルを前に出して早めに捉える
  diagram:
    players:

    shots:

      - { from: B, to: A.front, type: volleyDink, n: 2 }
    zones: [left]
  builderDefault:
    min: 2
    sets: 5
  related:
