---
title: クロスに受け流す
description: 相手の鋭いクロスのディンク・ドロップを、ノーバウンドでクロスに受け流して5thで攻めさせない
drill:
  id: 4th001
  category: 4th
  aliases:
    - クロスボレーで受け流す
    - 4thで浮かせない
  purpose: 相手の鋭い3rdクロスドロップや強めのクロスディンクを、浮かせずにノーバウンドでクロスへ受け流す。4thで浮かせないことで、相手に5thで攻めさせない。
  setup: 2人1組でクロス（対角）に入る。片方が球出し役、もう片方がキッチンライン付近で受ける練習役。1面で2組同時にできる。
  feed: 球出し役が、練習役の足元〜腰の高さへ強めのクロスボールを出す（どこから出すかは派生形ごとに変わる）。
  steps:
    - 練習役はキッチンライン付近で、パドルを体の前に構えて待つ
    - 来た球をノーバウンドでクロスへ返す（バウンドさせない）
    - 返したらすぐ構え直す。ラリー無しの派生形では、次の球出しを待つ
    - 一定時間で球出し役と練習役を交代する
  points:
    - 振らずに面を作って当てるだけ。相手のボールの勢いを使う
    - 返球はネットより低く、相手の足元へ沈める
    - 体の正面で取らず、パドルを前に出して早めに捉える
  variants:
    - key: dink
      name: クロスディンク → クロスボレーでラリー
      feed: キッチンからクロスディンクを出す
      steps:
        - 練習役はクロスディンクをノーバウンドボレーでクロスに返す
        - そのままラリーを続ける
    - key: half
      name: 半面・強めの斜めディンクをノーバウンドボレー
      feed: キッチンから、半面の斜めに強めのディンクを出す
      note: ラリーあり。全てノーバウンドボレーで斜めに返す。
    - key: full
      name: 全面・強めのクロスディンクをノーバウンドボレー
      feed: キッチンから強めのクロスディンクを出す
      note: ラリー無し。
    - key: tran
      name: トランからのクロスドロップをノーバウンドボレー
      feed: トランから強めのクロスドロップを出す
      note: ラリー無し。
    - key: base
      name: ベースラインからのクロスドロップをノーバウンドボレー
      feed: ベースラインから強めのクロスドロップを出す
      note: ラリー無し。ベースラインからの少し高めのクロスドロップをクロスディンクで流す形にしてもよい。
    - key: return
      name: リターン → クロスドロップ → ノーバウンドボレー
      setup: 練習役がリターン側、相手役がサーブ側
      feed: 練習役（リターン側）が、そんなに強くないリターンを出す
      steps:
        - サーブ側はリターンを強めにクロスドロップする
        - リターン側は前に詰め、全てノーバウンドボレーでクロスに返す
      note: ラリー無し。
  time:
    min: 2
    sets: 5
  related:
    - 4th002
    - drp002
    - trn002
---
