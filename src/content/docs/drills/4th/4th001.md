---
title: 半面・強めの斜めディンクをノーバウンドボレー
description: 半面で強めの斜めのディンクをノーバウンドボレーで斜めに受け流し、そのままラリーする
drill:
  id: 4th001
  category: 4th
  aliases:
    - 4thで浮かせない
  purpose: 相手の強めのディンクを、浮かせずにノーバウンドで斜めに受け流す。4thで浮かせないことで、相手に5thで攻めさせない。
  setup: 2人1組でコートの縦半分（半面）を使う。片方が球出し役、もう片方がキッチンライン付近で受ける練習役。1面で2組同時にできる。
  feed: 球出し役がキッチンから半面の斜めに強めのディンクを出す。
  steps:
    - 練習役はキッチンライン付近で、パドルを体の前に構えて待つ
    - 来た球を全てノーバウンドボレーで斜めに返す
    - そのままラリーを続ける
    - 一定時間で球出し役と練習役を交代する
  points:
    - 振らずに面を作って当てるだけ。相手のボールの勢いを使う
    - 返球はネットより低く、相手の足元へ沈める
    - 体の正面で取らず、パドルを前に出して早めに捉える
  diagram:
    players:
      - { id: A, x: 6.5, y: 14, role: feed }
      - { id: B, x: 3.5, y: 30, role: practice }
    shots:
      - { from: A, to: B, type: dink, curve: 0.08, n: 1 }
      - { from: B, to: [7.5, 17], type: volley, curve: 0.08, n: 2 }
    zones: [left]
  time:
    min: 2
    sets: 5
  related:
    - 4th002
    - 4th006
---
