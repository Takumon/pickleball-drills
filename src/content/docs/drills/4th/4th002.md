---
title: 全面・強めのクロスディンクをノーバウンドボレー
description: 強めのクロスディンクをノーバウンドボレーでクロスに受け流す（ラリー無し）
drill:
  id: 4th002
  category: 4th
  aliases:
    - 4thで浮かせない
  purpose: 相手の強めのクロスディンクを、浮かせずにノーバウンドでクロスへ受け流す。4thで浮かせないことで、相手に5thで攻めさせない。
  setup: 2人1組でクロス（対角）に入る。片方が球出し役、もう片方がキッチンライン付近で受ける練習役。1面で2組同時にできる。
  feed: 球出し役がキッチンから強めのクロスディンクを出す。
  steps:
    - 練習役はキッチンライン付近で、パドルを体の前に構えて待つ
    - 来た球をノーバウンドボレーでクロスに返す
    - ラリーはせず、次の球出しを待つ
    - 一定時間で球出し役と練習役を交代する
  points:
    - 振らずに面を作って当てるだけ。相手のボールの勢いを使う
    - 返球はネットより低く、相手の足元へ沈める
    - 体の正面で取らず、パドルを前に出して早めに捉える
  diagram:
    players:
      - { id: A, x: 5, y: 14, role: feed }
      - { id: B, x: 15, y: 30, role: practice }
    shots:
      - { from: A, to: B, type: dink, curve: 0.08, n: 1 }
      - { from: B, to: [4, 17], type: volley, curve: 0.08, n: 2 }
  time:
    min: 2
    sets: 5
  related:
    - 4th001
    - 4th003
    - 4th006
---
