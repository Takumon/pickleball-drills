---
title: トランからのクロスドロップをボレーディンク
description: トランから来る強めのクロスドロップを、ボレーディンクでクロスに受け流す（ラリー無し）
sidebar:
  order: 3
drill:
  id: 4th003
  category: 4th
  aliases:
    - 4thで浮かせない
  purpose: サーブ側はトランから3rdのクロスドロップを打って、キッチンへ上がろうとしている。このドロップをノーバウンドでクロスへ受け流すのは、4thで浮かせずに早いタイミングで返し、相手がキッチンへ上がる時間を与えず、5thで攻めさせないため。
  setup: 2人1組でクロス（対角）に入る。球出し役はトラン、練習役は対角のキッチンライン付近で、自分の半面の真ん中から少し球出し役の側に寄った位置（基本の位置）に立つ。フォアハンド同士なので、球は斜めに行き来する。1面で2組同時にできる。
  feed: 球出し役は手元で一度弾ませてから、トランから強めのクロスドロップを出す。
  steps:
    - 練習役は基本の位置で、パドルを体の前に構えて待つ
    - 球出し役が打ったら、サイドラインの側へサイドステップで横に動いて球に合わせる
    - 来た球をボレーディンクでクロスに返す
    - 返したらすぐに基本の位置へ戻る
    - ラリーはせず、次の球出しを待つ
    - 一定時間で球出し役と練習役を交代する
  points:
    - 振らずに面を作って当てるだけ。相手のボールの勢いを使う
    - 返球はネットより低く、相手の足元へ沈める
    - 体の正面で取らず、パドルを前に出して早めに捉える
  diagram:
    players:

    shots:

      - { from: B, to: far-leftSide-inKitchen, type: volleyDink, n: 2 }
      - { from: B, to: near-rightInner-kitchen, type: move, n: 2 }
  builderDefault:
    min: 2
    sets: 5
