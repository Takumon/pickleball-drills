---
title: トランからのクロスドロップをノーバウンドボレー
description: トランから来る強めのクロスドロップを、ノーバウンドボレーでクロスに受け流す（ラリー無し）
sidebar:
  order: 3
drill:
  id: 4th003
  category: 4th
  aliases:
    - 4thで浮かせない
  purpose: サーブ側はトランから3rdのクロスドロップを打って、キッチンへ上がろうとしている。このドロップをノーバウンドでクロスへ受け流すのは、4thで浮かせずに早いタイミングで返し、相手がキッチンへ上がる時間を与えず、5thで攻めさせないため。
  setup: 2人1組でクロス（対角）に入る。球出し役はトランのサイドライン寄り、練習役はキッチンライン付近の、対角のサイドラインに少し寄った位置に立つ。フォアハンド同士なので、球は大きく斜めに行き来する。1面で2組同時にできる。
  feed: 球出し役は手元で一度弾ませてから、トランから強めのクロスドロップを出す。
  steps:
    - 練習役はキッチンライン付近で、パドルを体の前に構えて待つ
    - 来た球をノーバウンドボレーでクロスに返す
    - ラリーはせず、次の球出しを待つ
    - 一定時間で球出し役と練習役を交代する
  points:
    - 振らずに面を作って当てるだけ。相手のボールの勢いを使う
    - 返球はネットより低く、相手の足元へ沈める
    - 体の正面で取らず、パドルを前に出して早めに捉える
  diagram:
    players:
      - { id: A, at: far-leftSide-tran, role: feed }
      - { id: B, at: near-rightOuter-kitchen, role: practice }
    shots:
      - { from: A, to: B, type: drop, n: 1, afterBounce: true }
      - { from: B, to: A.front, type: volleyDink, n: 2 }
  builderDefault:
    min: 2
    sets: 5
