---
title: ベースラインからのクロスドロップをノーバウンドボレー
description: ベースラインから来る強めのクロスドロップを、ノーバウンドボレーでクロスに受け流す（ラリー無し）
drill:
  id: 4th004
  category: 4th
  aliases:
    - 4thで浮かせない
  purpose: 相手の鋭い3rdクロスドロップを、浮かせずにノーバウンドでクロスへ受け流す。4thで浮かせないことで、相手に5thで攻めさせない。
  setup: 2人1組でクロス（対角）に入る。球出し役はベースラインの後ろ、練習役はキッチンライン付近に立つ。1面で2組同時にできる。
  feed: 球出し役がベースラインから強めのクロスドロップを出す。
  steps:
    - 練習役はキッチンライン付近で、パドルを体の前に構えて待つ
    - 来た球をノーバウンドボレーでクロスに返す
    - ラリーはせず、次の球出しを待つ
    - 一定時間で球出し役と練習役を交代する
  points:
    - 振らずに面を作って当てるだけ。相手のボールの勢いを使う
    - 返球はネットより低く、相手の足元へ沈める
    - 体の正面で取らず、パドルを前に出して早めに捉える
  diagram:
    players:
      - { id: A, x: 5, y: -2.5, role: feed }
      - { id: B, x: 15, y: 30, role: practice }
    shots:
      - { from: A, to: B, type: drop, curve: 0.08, n: 1 }
      - { from: B, to: [4, 4], type: volley, curve: 0.08, n: 2 }
  time:
    min: 2
    sets: 5
  related:
    - 4th003
    - 4th005
    - drp002
    - 4th011
