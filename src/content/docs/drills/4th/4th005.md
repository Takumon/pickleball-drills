---
title: リターン → クロスドロップ → ノーバウンドボレー
description: リターンしてから前に詰め、相手の強めのクロスドロップをノーバウンドボレーでクロスに受け流す（ラリー無し）
drill:
  id: 4th005
  category: 4th
  aliases:
    - 4thで浮かせない
  purpose: リターンから前に詰め、相手の鋭い3rdクロスドロップを浮かせずにノーバウンドでクロスへ受け流す。4thで浮かせないことで、相手に5thで攻めさせない。
  setup: 2人1組でクロス（対角）に入る。練習役がリターン側、相手役がサーブ側で、どちらもベースラインの後ろに立つ。1面で2組同時にできる。
  feed: 練習役（リターン側）がそんなに強くないリターンを出す。
  steps:
    - サーブ側はリターンを強めにクロスドロップする
    - リターン側は前に詰め、全てノーバウンドボレーでクロスに返す
    - ラリーはせず、リターンからやり直す
    - 一定時間でリターン側とサーブ側を交代する
  points:
    - 振らずに面を作って当てるだけ。相手のボールの勢いを使う
    - 返球はネットより低く、相手の足元へ沈める
    - 体の正面で取らず、パドルを前に出して早めに捉える
  diagram:

      - { from: A, to: [15.5, 31], type: drop, curve: 0.1, n: 3 }
      - { from: [15.5, 31], to: [1.5, 9], type: volley, n: 4 }
  time:
    min: 2
    sets: 5
