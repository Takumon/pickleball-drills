---
title: ストレートディンク
description: 正面の相手とキッチンライン付近でディンクを打ち合う
sidebar:
  order: 1
drill:
  id: dnk001
  category: dnk
  scene: 4人ともキッチンラインに並び、ディンクの打ち合いになっている。どちらかが浮いた球を出すと、相手にスピードアップで攻められる。
  purpose: ネットの低いところを通して相手のキッチンに落とし続け、相手が打てる高さの球を渡さない。相手が先に浮かせるまで待ち、浮いた球をこちらから攻める。
  focus: 正面の相手と同じ高さ・同じ深さのディンクを続け、打点と面の向きを合わせる。
  setup: 2人1組でストレート（正面）に向かい合い、2人ともキッチンライン付近に立つ。1面で2組同時にできる。
  feed: どちらかがディンクを出して始める。
  steps:
    - 2人ともキッチンライン付近で構える
    - 弾んだ球をディンクで正面の相手のキッチンに返す
    - そのままラリーを続ける
  points:
    - 大きく振らず、下から運ぶように打つ
    - ネットの少し上を通し、相手のキッチンに落とす
    - 膝を曲げて低い姿勢で打つ
  diagram:
    players:

    shots:
      - { from: A, to: B, type: dink, n: 1, bounce: front }
      - { from: B, to: A, type: dink, n: 2, bounce: front }
  variants:
    - { key: any, name: 自由, default: true, note: フォアでもバックでもよいのでディンク }
    - { key: fh, name: フォアのスライス, note: フォアのスライスでディンク（トラップあり） }
    - { key: bh, name: バックのスライス, note: バックのスライスでディンク（トラップあり） }
  builderDefault:
    min: 1
    sets: 5
