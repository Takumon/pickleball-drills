title: クロスディンク ラリー
description: 対角の相手とキッチンライン付近でクロスのディンクを打ち合う
sidebar:
  order: 4
drill:
  id: dnk003
  category: dnk
  scene: 4人ともキッチンラインに並び、ディンクの打ち合いになっている。どちらかが浮いた球を出すと、相手に攻められる。
  purpose: ネットの低いところを通して相手のキッチンに落とし続け、相手が打てる高さの球を渡さない。相手が先に浮かせるまで待ち、浮いた球をこちらから攻める。
  focus: 試合でいちばん多いクロスのディンクを、ネットの低い真ん中を通して続ける。
  setup: 2人1組でクロス（対角）に入り、2人ともキッチンライン付近に立つ。2人とも、自分の半面の真ん中から少し相手の側に寄った位置（基本の位置）で待つ。1面で2組同時にできる。
  feed: どちらかがクロスにディンクを出して始める。
  steps:
    - 2人とも基本の位置で構える
    - 相手が打ったら、サイドステップで横に動いて球に合わせ、打ったらすぐに基本の位置へ戻る
    - 弾んだ球をディンクで対角の相手のキッチンに返す
    - そのままラリーを続ける
  points:
    - ネットの一番低い真ん中あたりを通す
    - 体の横ではなく、体の前（足の前）で打つ
    - パドルのヘッドを下げた形から打ち出す。ストロークのように後ろから振らない
    - 打ったら必ず基本の位置へ戻る。最初から端で待たない
  diagram:
    players:
      - { id: A, at: far-leftOuter-kitchen, role: practice }
      - { id: B, at: near-rightInner-kitchen, role: practice }
    shots:
      # A は外側で受けたところから打ち、打ちながら基本の位置へ戻る。B は横へ動いて受け、打ちながら戻る。
      # 最後の手のあとの立ち位置が最初と同じになるので、繰り返しても人が跳ばない
      - { from: A, to: B, type: dink, n: 1, bounce: front }
      - { from: A, to: far-leftInner-kitchen, type: move, n: 1 }
      - { from: B, to: near-rightOuter-kitchen, type: move, n: 1 }
      - { from: B, to: A, type: dink, n: 2, bounce: front }
      - { from: B, to: near-rightInner-kitchen, type: move, n: 2 }
      - { from: A, to: far-leftOuter-kitchen, type: move, n: 2 }
  variants:
    - { key: any, name: 自由, default: true, note: フォアでもバックでもよいのでディンク }
    - { key: slice, name: スライス, note: スライスでディンク }
  builderDefault:
    min: 2
