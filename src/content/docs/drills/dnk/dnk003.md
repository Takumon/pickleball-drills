sidebar:
  order: 4
drill:
  id: dnk003
  category: dnk
  scene: 4人ともキッチンラインに並び、ディンクの打ち合いになっている。どちらかが浮いた球を出すと、相手に攻められる。
  purpose: 相手にノーバウンドで強く打たれない低さで、相手のキッチンに落とし続ける。コース・深さ・速さを変えて相手を揺さぶり、ミスや浮いた球を誘って、浮いた球をこちらから攻める。
  focus: いちばん多く打つクロスのディンクで、試合のつもりで打ち合い、コースと深さを変えて相手を揺さぶり、浮いた球を出させる。
  setup: 2人1組でクロス（対角）に入り、2人ともキッチンライン付近に立つ。2人とも、自分の半面の真ん中から少し相手の側に寄った位置（基本の位置）で待つ。1面で2組同時にできる。
  feed: どちらかがクロスにディンクを出して始める。
  steps:
    - 返すたびに、コース（角度）と深さ（ネット際からキッチンラインの近くまで）を変える
    - 球が途切れたら、ディンクから始め直す
  points:
    - 低い球は無理に打たず、ディンクで返す
    - 体の横ではなく、体の前（足の前）で打つ
    - パドルのヘッドを下げた形から打ち出す。ストロークのように後ろから振らない
    - 打ったら必ず基本の位置へ戻る。最初から端で待たない
    - 同じところに続けて返さず、コースと深さを散らす

    shots:

      - { from: B, to: A, type: dink, n: 2, bounce: front }
  # 浮いた球が来たときの攻め方は、基本の図から切り離して出す（書き手と決めた）

          - { from: B, to: A, type: dink, n: 1, peak: head, label: 浮いた球 }
