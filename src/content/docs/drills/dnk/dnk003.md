---
title: クロスディンク ラリー
description: 対角の相手とキッチンライン付近でクロスのディンクを打ち合う
sidebar:
  order: 3
drill:
  id: dnk003
  category: dnk
  scene: 4人ともキッチンラインに並び、ディンクの打ち合いになっている。どちらかが浮いた球を出すと、相手にスピードアップで攻められる。
  purpose: ネットの低いところを通して相手のキッチンに落とし続け、相手が打てる高さの球を渡さない。相手が先に浮かせるまで待ち、浮いた球をこちらから攻める。
  focus: 試合でいちばん多いクロスのディンクを、ネットの低い真ん中を通して続ける。
  setup: 2人1組でクロス（対角）に入り、2人ともキッチンライン付近に立つ。1面で2組同時にできる。
  feed: どちらかがクロスにディンクを出して始める。
  steps:
    - 2人ともキッチンライン付近で構える
    - 弾んだ球をディンクで対角の相手のキッチンに返す
    - そのままラリーを続ける
  points:
    - ネットの一番低い真ん中あたりを通す
    - 大きく振らず、下から運ぶように打つ
    - 打ったら自分の半面の真ん中に戻る
  diagram:
    players:
      - { id: A, at: far-left-kitchen, role: practice }
      - { id: B, at: near-right-kitchen, role: practice }
    shots:
      - { from: A, to: B, type: dink, n: 1, bounce: front }
      - { from: B, to: A, type: dink, n: 2, bounce: front }
  variants:
    - { key: any, name: 自由, default: true, note: フォアでもバックでもよいのでディンク }
    - { key: slice, name: スライス, note: スライスでディンク }
  builderDefault:
    min: 2
    sets: 5
