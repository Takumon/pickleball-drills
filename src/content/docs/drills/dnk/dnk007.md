title: クロスディンク 打ち方を決めて
description: 練習役 B が打ち方を1つ決めて、クロスのディンクをラリーで打ち続ける。球出し役 A は組み合わせの打ち方で返す
sidebar:

drill:
  id: dnk007
  category: dnk
  aliases:
    - クロスディンク 片方ロール・片方スライス/ショートホップ
  scene: 4人ともキッチンラインに並び、ディンクの打ち合いになっている。どちらかが浮いた球を出すと、相手に攻められる。
  purpose: 相手にノーバウンドで強く打たれない低さで、相手のキッチンに落とし続ける。コース・深さ・速さを変えて相手を揺さぶり、ミスや浮いた球を誘って、浮いた球をこちらから攻める。
  focus: 打ち方を1つに決めて、ラリーの中でも同じ形で打ち続け、ロール・スライス・ショートホップのディンクの形を固める。
  setup: 2人1組でクロス（対角）に入り、2人ともキッチンライン付近に立つ。自分の半面の真ん中から少し相手の側に寄った位置（基本の位置）で待つ。練習役 B が打ち方を1つ（ロール・スライス・ショートホップ）決め、球出し役 A はそれに合わせた打ち方で返す（B がロールなら A はスライス、B がスライスなら A はロール、B がショートホップなら A はロール）。1面で2組同時にできる。
  feed: 球出し役 A が手元で一度弾ませてから、練習役 B へクロスのディンクを出して始める。返ってきた球は、A が組み合わせの打ち方でそのままラリーで返す。
  steps:
    - 練習役 B は基本の位置で構えて待つ
    - 相手が打ったら、サイドステップで横に動いて球に合わせる
    - B は決めた打ち方、A は組み合わせの打ち方のディンクでクロスに返す（ロールは鋭いクロス、スライスは相手の手前、ショートホップは少し真ん中寄りのネット際）
    - 返したらすぐに基本の位置へ戻る
    - 一定時間で球出し役と練習役を交代し、打ち方も変える
  # 練習のコツ: 共通の2つ＋打ち方ごとの3つ（派生形を切り替えると、ここも切り替わる。書き手と決めた）
  points:
    - 体の横ではなく、体の前（足の前）で打つ
    - 打ったら必ず基本の位置へ戻る。最初から端で待たない
    - ヘッドを下げた所から、球の後ろを下から上へこすり上げて順回転をかける
    - 振り抜きを狙う方向（鋭いクロス）へ向ける。手首でこねない
    - 決めた打ち方を変えず、毎回同じ形で打つ
  notes: 同じ練習を1球ずつ球出しで行う形がひとつ上の「クロスディンク 打ち方を決めて」（ラリーなし）。違いはラリーをするかどうかだけ。ラリーでは、球出し役 A が B の打ち方に合わせた打ち方で返す。
  diagram:
    rally: 2
    # B がロール、A がスライス（書き手の決まり）。ロールは鋭いクロスなので、受ける A はサイドライン寄りまで動いて取る
    players:
      - { id: A, at: far-leftInner-kitchen, sidestep: far-leftSide-kitchen, role: feed }
      - { id: B, at: near-rightInner-kitchen, sidestep: near-rightOuter-kitchen, role: practice }
    shots:
      - { from: A, to: B, type: sliceDink, n: 1, bounce: front }
      - { from: B, to: A, type: rollDink, n: 2, bounce: front, label: ロール }
  variants:
    - { key: roll, name: ロール, default: true, note: B はロール、A はスライスでラリーする }
    - key: slice
      name: スライス

      points:
        - 体の横ではなく、体の前（足の前）で打つ
        - 打ったら必ず基本の位置へ戻る。最初から端で待たない
        - 面を少し上へ開いたまま手首を固め、短く前へ運ぶ。上から下へ切らない
        - 相手の手前に低く落とし、弾んだあとも低く滑らせる
        - 決めた打ち方を変えず、毎回同じ形で打つ
      diagram:
        rally: 2
        # B がスライス、A がロール。ロールを受ける B はサイドライン寄りまで動いて取る
        players:
          - { id: A, at: far-leftInner-kitchen, sidestep: far-leftOuter-kitchen, role: feed }
          - { id: B, at: near-rightInner-kitchen, sidestep: near-rightSide-kitchen, role: practice }
        shots:
          - { from: A, to: B, type: rollDink, n: 1, bounce: front, label: ロール }
          - { from: B, to: A, type: sliceDink, n: 2, bounce: front }
    - key: hop
      name: ショートホップ
      note: B はショートホップ、A はロールでラリーする
      points:
        - 体の横ではなく、体の前（足の前）で打つ
        - 打ったら必ず基本の位置へ戻る。最初から端で待たない
        - 先に動いて止まり、低く構えて、弾んだ直後の上がりきる前に取る
        - 打つ前に手首を固め、面を狙う方向へ向けておく。打つ瞬間に面を合わせにいかない
        - 真ん中寄りのネット際へ短く落とし、相手にスピードアップさせない
      diagram:
        rally: 2

        players:
          - { id: A, at: far-leftInner-kitchen, sidestep: far-leftCenter-kitchen, role: feed }
          - { id: B, at: near-rightInner-kitchen, sidestep: near-rightSide-kitchen, role: practice }
        shots:
          - { from: A, to: B, type: rollDink, n: 1, bounce: front, label: ロール }
          - { from: B, to: A, type: shortHop, n: 2, bounce: front }
