title: クロスディンク 打ち方を決めて
description: 決めた打ち方（ロール・スライス・ショートホップ）で、クロスのディンクをラリーで打ち続ける
sidebar:
  order: 8
drill:
  id: dnk007
  category: dnk
  aliases:
    - クロスディンク 片方ロール・片方スライス/ショートホップ
  scene: 4人ともキッチンラインに並び、ディンクの打ち合いになっている。どちらかが浮いた球を出すと、相手に攻められる。
  purpose: 相手にノーバウンドで強く打たれない低さで、相手のキッチンに落とし続ける。コース・深さ・速さを変えて相手を揺さぶり、ミスや浮いた球を誘って、浮いた球をこちらから攻める。
  focus: 打ち方を1つに決めて、ラリーの中でも同じ形で打ち続け、ロール・スライス・ショートホップのディンクの形を固める。
  setup: 2人1組でクロス（対角）に入り、2人ともキッチンライン付近に立つ。自分の半面の真ん中から少し相手の側に寄った位置（基本の位置）で待つ。打ち方を1つ（ロール・スライス・ショートホップ）決める。2人とも練習役になる。1面で2組同時にできる。
  feed: どちらかが手元で一度弾ませてから、クロスにディンクを出して始める。返ってきた球はそのままラリーで返す。
  steps:
    - 2人とも基本の位置で構えて待つ
    - 相手が打ったら、サイドステップで横に動いて球に合わせる
    - 来た球を、決めた打ち方のディンクでクロスに返す（ロールは鋭いクロス、スライスは相手の手前、ショートホップは少し真ん中寄りのネット際）
    - 返したらすぐに基本の位置へ戻る
    - 一定時間で打ち方を変える
  points:
    - 体の横ではなく、体の前（足の前）で打つ
    - パドルのヘッドを下げた形から打ち出す。ストロークのように後ろから振らない
    - 決めた打ち方を変えず、毎回同じ形で打つ
    - 打ったら必ず基本の位置へ戻る。最初から端で待たない
  notes: 同じ練習を1球ずつ球出しで行う形がひとつ上の「クロスディンク 打ち方を決めて」（ラリーなし）。違いはラリーをするかどうかだけ。
  diagram:
    rally: 2
    # ロール: いちばん速く、鋭いクロス（サイドライン寄り）を狙うので、受ける人はサイドライン寄りまで動いて取る（書き手の指摘）
    players:
      - { id: A, at: far-leftInner-kitchen, sidestep: far-leftSide-kitchen, role: practice }
      - { id: B, at: near-rightInner-kitchen, sidestep: near-rightSide-kitchen, role: practice }
    shots:
      - { from: A, to: B, type: rollDink, n: 1, bounce: front, label: ロール }
      - { from: B, to: A, type: rollDink, n: 2, bounce: front, label: ロール }
  variants:
    - { key: roll, name: ロール, default: true, note: ロール（トップスピン）でディンク }
    - key: slice
      name: スライス
      note: スライスでディンク
      diagram:
        rally: 2
        players:
          - { id: A, at: far-leftInner-kitchen, sidestep: far-leftOuter-kitchen, role: practice }
          - { id: B, at: near-rightInner-kitchen, sidestep: near-rightOuter-kitchen, role: practice }
        shots:
          - { from: A, to: B, type: sliceDink, n: 1, bounce: front }

    - key: hop
      name: ショートホップ
      note: 弾んだ直後の低いところを打つショートホップでディンク
      diagram:
        rally: 2
        # ショートホップ: スライスより少し真ん中寄りの短い所を狙うので、受ける人は真ん中寄りで取る（書き手の指摘）
        players:
          - { id: A, at: far-leftInner-kitchen, sidestep: far-leftCenter-kitchen, role: practice }
          - { id: B, at: near-rightInner-kitchen, sidestep: near-rightCenter-kitchen, role: practice }
        shots:
          - { from: A, to: B, type: shortHop, n: 1, bounce: front }
          - { from: B, to: A, type: shortHop, n: 2, bounce: front }

    min: 2
