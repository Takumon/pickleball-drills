description: クロスのディンクのラリーで、片方はロール、もう片方はスライスかショートホップだけで打つ
sidebar:
  order: 8
drill:
  id: dnk007
  category: dnk
  scene: 4人ともキッチンラインに並び、ディンクの打ち合いになっている。どちらかが浮いた球を出すと、相手に攻められる。
  purpose: ネットの低いところを通して相手のキッチンに落とし続け、相手が打てる高さの球を渡さない。相手が先に浮かせるまで待ち、浮いた球をこちらから攻める。
  focus: 回転の違う球を受けながら打ち合い、相手の球に合わせて自分の打ち方を保つ。
  setup: 2人1組でクロス（対角）に入り、2人ともキッチンライン付近に立つ。2人とも、自分の半面の真ん中から少し相手の側に寄った位置（基本の位置）で待つ。片方はロールだけ、もう片方はスライスかショートホップだけで打つ。1面で2組同時にできる。
  feed: どちらかがクロスにディンクを出して始める。
  steps:
    - 2人とも基本の位置で構える
    - 相手が打ったら、サイドステップで横に動いて球に合わせ、打ったらすぐに基本の位置へ戻る
    - A はロールのディンク、B はスライスかショートホップのディンクだけで、クロスに打ち合う
    - そのままラリーを続ける
    - 一定時間で打ち方を入れ替える
  points:
    - 体の横ではなく、体の前（足の前）で打つ
    - パドルのヘッドを下げた形から打ち出す。ストロークのように後ろから振らない
    - 相手の回転で球の弾み方が変わるので、弾んだあとの球をよく見る
    - 打ったら必ず基本の位置へ戻る。最初から端で待たない
  diagram:
    players:

      - { id: B, at: near-rightInner-kitchen, sidestep: near-rightOuter-kitchen, role: practice }
    shots:

  builderDefault:
    min: 2
