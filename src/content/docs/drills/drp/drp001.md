---
title: トランからストレートドロップ
description: トランから相手のキッチンに落ちるドロップをストレートに打つ
drill:
  id: drp001
  category: drp
  purpose: トランから、相手のキッチンに落ちるドロップをストレートに打てるようにする。
  setup: 2人1組でストレート（正面）に向かい合う。球出し役はキッチンライン付近、練習役はトランに立つ。1面で2組同時にできる。
  feed: 球出し役がキッチンから練習役のトランへ球を出す。
  steps:
    - 練習役はトランで構えて待つ
    - 来た球をストレートにドロップし、相手のキッチンに落とす
    - 球出し役は次の球を出して続ける
    - 一定時間で球出し役と練習役を交代する
  points:
    - ネットの少し上を通し、相手のキッチンに落とす
    - 大きく振らず、下から運ぶように打つ
    - 打ったら前に詰める準備をする
  diagram:
    players:
      - { id: A, x: 5, y: 14, role: feed }
      - { id: B, x: 5, y: 35, role: practice }
    shots:
      - { from: A, to: B, type: feed, curve: 0.08, n: 1 }
      - { from: B, to: [5.5, 18], type: drop, curve: 0.08, n: 2 }
    zones: [tran-bottom]
  variants:
    - key: fh
      name: フォア
      note: フォアハンドで打つ。
    - key: bh
      name: バック
      note: バックハンドで打つ。
  time:
    min: 2
    sets: 5
  related:
    - drp002
    - rst006
