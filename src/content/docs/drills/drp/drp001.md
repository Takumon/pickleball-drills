---
title: トランからストレートドロップ
description: トランから相手のキッチンに落ちるドロップをストレートに打つ
sidebar:
  order: 1
drill:
  id: drp001
  category: drp
  scene: 3rdをストロークで打ち、キッチンにいる相手にボレーで返された。トランまで詰めたところで、5thを打つ。
  purpose: 5thを確実にドロップで相手のキッチンに落とし、続けて攻められずにキッチンへ上がる。
  focus: トランから、ストレートに柵の内側へ落とす。
  setup: 2人1組でストレート（正面）に向かい合う。球出し役はキッチンライン付近、練習役はトランに立つ。相手のキッチンには、サイドラインから40cm、キッチンラインからパドル1本分の位置に柵をL字に置く。1面で2組同時にできる。
  feed: 球出し役がキッチンから練習役のトランへ球を出す。
  steps:
    - 練習役はトランで構えて待つ
    - 来た球をストレートにドロップし、柵に当てずに内側へ落とす
    - 球出し役は次の球を出して続ける
    - 一定時間で球出し役と練習役を交代する
  points:
    - ネットの上は少し余裕を持って通し、相手が打つところで低くなるように相手のキッチンに落とす
    - 大きく振らず、下から運ぶように打つ
    - 打ったら前に詰める準備をする
  diagram:
    rally: false
    fence: far-left
    players:
      - { id: A, at: far-left-kitchen, role: feed }
      - { id: B, at: near-left-tran, role: practice }
    shots:
      - { from: A, to: B, type: dink, feed: true, n: 1, bounce: front }
      - { from: B, to: fence.inside, type: drop, n: 2 }
  variants:
    - key: fh
      default: true
      name: フォア
      note: フォアでドロップ
    - key: bh
      name: バック
      note: バックでドロップ
  builderDefault:
    min: 2
    sets: 5
