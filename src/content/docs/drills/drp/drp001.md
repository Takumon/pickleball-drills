---
title: トランからストレートドロップ
description: トランから相手のキッチンに落ちるドロップをストレートに打つ
drill:
  id: drp001
  category: drp
  purpose: サーブ側はベースラインからトランまで上がってきて、キッチンまであと一歩のところにいる。ここで確実にドロップを相手のキッチンに落とせば、スマッシュや強めの球を打ち返されないまま、キッチンへ上がれる。
  setup: 2人1組でストレート（正面）に向かい合う。球出し役はキッチンライン付近、練習役はトランに立つ。相手のキッチンには、サイドラインから40cm、キッチンラインからパドル1本分の位置に柵をL字に置く。1面で2組同時にできる。
  feed: 球出し役がキッチンから練習役のトランへ球を出す。
  steps:
    - 練習役はトランで構えて待つ
    - 来た球をストレートにドロップし、柵に当てずに内側へ落とす
    - 球出し役は次の球を出して続ける
    - 一定時間で球出し役と練習役を交代する
  points:
    - ネットの少し上を通し、相手のキッチンに落とす
    - 大きく振らず、下から運ぶように打つ
    - 打ったら前に詰める準備をする
  diagram:
    fences:

      - { from: B, to: [3.5, 18.5], type: drop, curve: 0.08, n: 2 }

      note: バックハンドで打つ。
  time:
    min: 2
    sets: 5
