---
title: トランからのクロスドロップ
description: トランから相手のキッチンに落ちるドロップをクロスに打つ
sidebar:
  order: 2
drill:
  id: drp002
  category: drp
  scene: トランからキッチンへ上がるあと一歩のところにいる。クロスはストレートより距離が長く、ネットのいちばん低い真ん中を通せるので、キッチンに落としやすい。
  purpose: ドロップを確実にクロスに落とし、相手に強い球を打たせずにキッチンへ上がる。
  setup: 2人1組でクロス（対角）に入る。球出し役はキッチンライン付近、練習役はトランに立つ。相手のキッチンには、サイドラインから40cm、キッチンラインからパドル1本分の位置に柵をL字に置く。1面で2組同時にできる。
  feed: 球出し役がキッチンからクロスに、練習役のトランへ球を出す。
  steps:
    - 練習役はトランで構えて待つ
    - 来た球をクロスにドロップし、柵に当てずに柵の角のすぐ内側へ落とす
    - 球出し役は次の球を出して続ける
    - 一定時間で球出し役と練習役を交代する
  points:
    - ネットの一番低い真ん中あたりを通す
    - 大きく振らず、下から運ぶように打つ
    - 打ったら前に詰める準備をする
  diagram:
    fence: far-left
    players:
      - { id: A, at: far-left-kitchen, role: feed }
      - { id: B, at: near-right-tran, role: practice }
    shots:
      - { from: A, to: B, type: dink, feed: true, n: 1, bounce: front }
      - { from: B, to: fence.corner, type: drop, n: 2 }
  variants:
    - key: slice
      name: スライス
      note: スライスで打つ。
    - key: roll
      name: ロール
      note: ロール（トップスピン）で打つ。
  builderDefault:
    min: 2
    sets: 5
