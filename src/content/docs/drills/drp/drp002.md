---
title: クロスドロップ
description: トランから相手のキッチンに落ちるドロップをクロスに打つ
drill:
  id: drp002
  category: drp
  purpose: トランから、相手のキッチンに落ちるドロップをクロスに打てるようにする。
  setup: 2人1組でクロス（対角）に入る。球出し役はキッチンライン付近、練習役はトランに立つ。1面で2組同時にできる。
  feed: 球出し役がキッチンからクロスに、練習役のトランへ球を出す。
  steps:
    - 練習役はトランで構えて待つ
    - 来た球をクロスにドロップし、相手のキッチンに落とす
    - 球出し役は次の球を出して続ける
    - 一定時間で球出し役と練習役を交代する
  points:
    - ネットの一番低い真ん中あたりを通す
    - 大きく振らず、下から運ぶように打つ
    - 打ったら前に詰める準備をする
  diagram:
    players:
      - { id: A, x: 5, y: 14, role: feed }
      - { id: B, x: 15, y: 36.5, role: practice }
    shots:
      - { from: A, to: B, type: feed, curve: 0.08, n: 1 }
      - { from: B, to: [5.5, 18], type: drop, curve: 0.08, n: 2 }
  variants:
    - key: slice
      name: スライス
      note: スライスで打つ。
    - key: roll
      name: ロール
      note: ロール（トップスピン）で打つ。
  time:
    min: 2
    sets: 5
  related:
    - drp001
    - drp003
    - 4th003
---
