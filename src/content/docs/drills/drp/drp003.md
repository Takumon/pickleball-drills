---
title: リターン → クロスドロップ
description: 相手のリターンを、ベースラインからクロスにドロップする
drill:
  id: drp003
  category: drp
  purpose: 試合と同じ流れで、リターンされた深い球をベースラインからクロスにドロップする（3rdショットドロップ）。
  setup: 2人1組でクロス（対角）に入る。相手役はリターン側、練習役はサーブ側の、それぞれベースラインの後ろに立つ。1面で2組同時にできる。
  feed: 相手役が練習役のベースライン付近へリターンを出す。
  steps:
    - 練習役はベースラインの後ろで構えて待つ
    - リターンされた球をクロスにドロップし、相手のキッチンに落とす
    - 相手役は次のリターンを出して続ける
    - 一定時間で相手役と練習役を交代する
  points:
    - リターンが深く来ることを前提に、早めに下がって準備する
    - ネットの一番低い真ん中あたりを通す
    - 大きく振らず、下から運ぶように打つ
  diagram:
    players:
      - { id: A, x: 5, y: -2.5, role: opponent }
      - { id: B, x: 15, y: 46.5, role: practice }
    shots:
      - { from: A, to: B, type: return, curve: 0.08, n: 1, bounce: [14, 41] }
      - { from: B, to: [5.5, 18], type: drop, curve: 0.08, n: 2 }
  time:
    min: 2
    sets: 10
  related:
    - drp002
    - drp004
    - 4th005
