---
title: クロスドロップ
description: ベースラインの後ろから、相手のキッチンに落ちるドロップをクロスに打つ
sidebar:
  order: 3
drill:
  id: drp003
  category: drp
  scene: サーブ側として、深いリターンをベースラインの後ろから3rdショットで打つ。リターン側はもうキッチンにいるので、強く打つと上から叩かれやすい。
  purpose: 3rdショットをクロスのドロップで相手のキッチンに落として相手に下から打ち上げさせ、そのあいだに前へ上がる。
  focus: 球出しの深い球を使い、いちばん遠い位置から柵の角をねらってクロスに落とす。
  setup: 2人1組でクロス（対角）に入る。球出し役はキッチンライン付近、練習役はベースラインの後ろに立つ。相手のキッチンには、サイドラインから40cm、キッチンラインからパドル1本分の位置に柵をL字に置く。1面で2組同時にできる。
  feed: 球出し役がキッチンからクロスに、練習役のベースライン付近へ深い球を出す。
  steps:
    - 練習役はベースラインの後ろで構えて待つ
    - 来た球をクロスにドロップし、柵に当てずに柵の角のすぐ内側へ落とす
    - 球出し役は次の球を出して続ける
    - 一定時間で球出し役と練習役を交代する
  points:
    - ネットの一番低い真ん中あたりを通す
    - 大きく振らず、膝を使って下から運ぶように打つ
    - 打ったら前に詰める準備をする
  diagram:
    fence: far-left

      - { id: B, at: near-right-baseline, role: practice }
    shots:

      - { from: B, to: fence.corner, type: drop, n: 2 }
  builderDefault:
    min: 2
    sets: 5
