---
title: サーブ → リターン → クロスドロップ
description: 自分のサーブから始め、相手のリターンをクロスにドロップする
drill:
  id: drp004
  category: drp
  purpose: サーブから3rdショットドロップまでを、試合と同じ順番で打てるようにする。
  setup: 2人1組でクロス（対角）に入る。練習役はサーブ側、相手役はリターン側の、それぞれベースラインの後ろに立つ。1面で2組同時にできる。
  feed: 練習役のサーブから始める。
  steps:
    - 練習役がクロスにサーブを打つ
    - 相手役がリターンを打つ
    - 練習役はリターンをクロスにドロップし、相手のキッチンに落とす
    - 一定時間で相手役と練習役を交代する
  points:
    - サーブを打ったら、すぐベースラインの後ろで構え直す
    - ネットの一番低い真ん中あたりを通す
    - 大きく振らず、下から運ぶように打つ
  diagram:
    players:

      - { from: A, to: B, type: return, curve: 0.12, n: 2 }
      - { from: B, to: [8, 18], type: drop, n: 3 }
  time:
    min: 2
    sets: 5
