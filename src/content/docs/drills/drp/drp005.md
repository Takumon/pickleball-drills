---
title: サーブ → リターン → クロスドロップ
description: 自分のサーブから始め、相手のリターンをクロスにドロップする
sidebar:
  order: 5
drill:
  id: drp005
  category: drp
  purpose: 試合では、サーブのあとに構え直しが遅れると、深いリターンに詰まってドロップが浮きやすい。サーブから3rdショットのドロップまでを試合と同じ順番で打つのは、構え直してから確実にキッチンへ落とし、前へ上がるため。
  setup: 2人1組でクロス（対角）に入る。練習役はサーブ側、相手役はリターン側の、それぞれベースラインの後ろに立つ。相手のキッチンには、サイドラインから40cm、キッチンラインからパドル1本分の位置に柵をL字に置く。1面で2組同時にできる。
  feed: 練習役のサーブから始める。
  steps:
    - 練習役がクロスにサーブを打つ
    - 相手役がリターンを打つ
    - 練習役はリターンをクロスにドロップし、柵に当てずに柵の角のすぐ内側へ落とす
    - 一定時間で相手役と練習役を交代する
  points:
    - サーブを打ったら、すぐベースラインの後ろで構え直す
    - ネットの一番低い真ん中あたりを通す
    - 大きく振らず、下から運ぶように打つ
  diagram:
    fence: far-left
    players:
      - { id: A, at: far-left-baseline, role: opponent }
      - { id: B, at: near-right-baseline, role: practice }
    shots:
      - { from: B, to: A, type: serve, n: 1, bounce: front }
      - { from: A, to: B, type: return, n: 2, bounce: front }
      - { from: B, to: fence.corner, type: drop, n: 3 }
  builderDefault:
    min: 2
    sets: 5
