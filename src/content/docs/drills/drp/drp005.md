---
title: サーブ → リターン → クロスドロップ
description: 自分のサーブから始め、相手のリターンをクロスにドロップする
sidebar:
  order: 5
drill:
  id: drp005
  category: drp
  scene: サーブ側として、深いリターンをベースラインの後ろから3rdショットで打つ。リターン側はもうキッチンにいるので、強く打つと上から叩かれやすい。
  purpose: 3rdショットをクロスのドロップで相手のキッチンに落として相手に下から打ち上げさせ、そのあいだに前へ上がる。
  focus: サーブから始め、サーブのあとに構え直してから、深いリターンに詰まらずに落とす。
  setup: 2人1組でクロス（対角）に入る。練習役はサーブ側、相手役はリターン側の、それぞれベースラインの後ろに立つ。相手のキッチンには、サイドラインから40cm、キッチンラインからパドル1本分の位置に柵をL字に置く。1面で2組同時にできる。
  feed: 練習役のサーブから始める。
  steps:
    - 練習役がクロスにサーブを打つ
    - 相手役がリターンを打つ
    - 練習役はリターンをクロスにドロップし、柵に当てずに柵の角のすぐ内側へ落とす
    - 一定時間で相手役と練習役を交代する
  points:
    - サーブを打ったら、すぐベースラインの後ろで構え直す
    - ネットの一番低い真ん中あたりを通す
    - 大きく振らず、下から運ぶように打つ

      - { from: A, to: B, type: return, n: 2, bounce: front }
      - { from: B, to: fence.corner, type: drop, n: 3 }
  builderDefault:
    min: 2
