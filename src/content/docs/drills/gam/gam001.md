sidebar:

drill:
  id: gam001
  category: gam
  aliases:
    - 共有スコアのクロスディンク
  scene: 4人ともキッチンラインに並び、ディンクの打ち合いになっている。どちらかが浮いた球を出すと、相手に攻められる。
  purpose: ネットの上は余裕を持って通し、相手が打つところでは低くなる球を相手のキッチンに落とし続ける。相手がノーバウンドで強く打てる高さの球を渡さない。相手が先に浮かせるまで待ち、浮いた球をこちらから攻める。
  focus: 1点ごとにスコアが行き来する中で、無理に攻めずに相手が浮かせるのを待ち、浮いた球を確実に決める。
  setup: 2人1組でクロス（対角）に入り、2人ともキッチンライン付近に立つ。2人とも、自分の半面の真ん中から少し相手の側に寄った位置（基本の位置）で待つ。スコアは2人で1つだけ持つ。1面で2組同時にできる。
  feed: どちらかがクロスにディンクを出して始める。
  steps:
    - 勝ちの点を決める（短くやるなら2点、長くやるなら5点）。スコアを0から始める
    - クロスのディンクで打ち合う。浮いた球は攻めてよい
    - B がその球の勝負に勝ったら +1、A が勝ったら −1 にする
    - スコアが +（勝ちの点）になったら B の勝ち、−（勝ちの点）になったら A の勝ち。スコアを0に戻して次のゲームを始める
  points:
    - 体の横ではなく、体の前（足の前）で打つ
    - パドルのヘッドを下げた形から打ち出す。ストロークのように後ろから振らない
    - 自分から無理に攻めず、相手が浮かせるまで低く返し続ける
    - 打ったら必ず基本の位置へ戻る。最初から端で待たない
  notes: 例えば2点で勝負するとき、スコアは 0 → −1 → 0 → +1 → +2（B の勝ち）と動く。勝っている人も1点落とせば0に戻るので、最後まで気を抜けない。
  diagram:
    rally: true
    players:
      - { id: A, at: far-leftInner-kitchen, sidestep: far-leftOuter-kitchen, role: practice }
      - { id: B, at: near-rightInner-kitchen, sidestep: near-rightOuter-kitchen, role: practice }
    # 2点で勝負する例: 0 → −1（A）→ 0 → +1 → +2（B の勝ち）。点が増える側（右・+）は手前の B。決まる球（point）は攻めのディンクで、相手の届かないキッチンの角に落ちる
    score: { to: 2, plus: B, minus: A }
