---
title: スマッシュ
description: キッチンライン付近で、上がった球をスマッシュで打ち込む
drill:
  id: lob001
  category: lob
  purpose: 浮いた球を逃さず、スマッシュで確実に打ち込めるようにする。
  setup: 2人1組でストレート（正面）に向かい合う。球出し役はトラン、練習役はキッチンライン付近に立つ。1面で2組同時にできる。
  feed: 球出し役が練習役の頭上に短めの高い球を上げる。
  steps:
    - 練習役はキッチンライン付近で構えて待つ
    - 上がった球をスマッシュで相手コートに打ち込む
    - 球出し役は次の球を出して続ける
    - 一定時間で球出し役と練習役を交代する
  points:
    - 横向きになり、利き手と反対の手で球を指す
    - 打点は頭の前の高いところ
    - 相手の足元に打ち込む
  diagram:
    players:
      - { id: A, x: 5, y: 10, role: feed }
      - { id: B, x: 5, y: 30, role: practice }
    shots:
      - { from: A, to: B, type: lob, curve: 0.15, n: 1 }
      - { from: B, to: [5.5, 11], type: smash, curve: -0.05, n: 2 }
  time:
    min: 2
    sets: 5
  related:
    - lob002
---
