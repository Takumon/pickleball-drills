---
title: スマッシュ
description: キッチンライン付近で、上がった球をスマッシュで打ち込む
sidebar:
  order: 1
drill:
  id: lob001
  category: lob
  scene: キッチンでラリー中に、相手のロブが短く浮いた。ポイントを決める好機になる。
  purpose: 浮いた球を逃さず、確実にスマッシュで打ち込んでポイントを取りきる。
  focus: 球出しの短く浮いた球を、キッチンライン付近から続けて打ち込み、スマッシュの打点と振りを安定させる。
  setup: 2人1組でストレート（正面）に向かい合う。球出し役はトラン、練習役はキッチンライン付近に立つ。1面で2組同時にできる。
  feed: 球出し役は手元で一度弾ませてから、練習役の頭上に短めの高い球を上げる。
  steps:
    - 球出し役は次の球を出して続ける
    - 一定時間で球出し役と練習役を交代する
  points:
    - 横向きになり、利き手と反対の手で球を指す
    - 打点は頭の前の高いところ
    - 相手の足元に打ち込む
  diagram:
    rally: false
    players:
      - { id: A, at: far-left-tran, role: feed }
      - { id: B, at: near-left-kitchen, role: practice }
    shots:
      - { from: A, to: B, type: lob, n: 1, afterBounce: true }
      - { from: B, to: [5.5, 11], type: smash, n: 2 }
  builderDefault:
    min: 2
    sets: 5
