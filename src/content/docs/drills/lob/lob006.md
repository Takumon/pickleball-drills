---
title: クロスのスマッシュ
description: キッチンライン付近で、上がった球を逆サイドの外側へクロスのスマッシュで打ち込む
sidebar:
  order: 2
drill:
  id: lob006
  category: lob
  scene: キッチンでラリー中に、相手のロブが短く浮いた。ポイントを決める好機になる。
  purpose: 浮いた球を逃さず、確実にスマッシュで打ち込んでポイントを取りきる。
  focus: 短く浮いた球を、逆サイドの外側（キッチンラインとトランの間）へクロスに打ち込み、相手が届かないところに決める。
  setup: 2人1組でストレート（正面）に向かい合う。球出し役はトラン、練習役はキッチンライン付近に立つ。スマッシュは逆サイドへ打つので、1面を1組で使う。
  feed: 球出し役は手元で一度弾ませてから、練習役の頭上に短めの高い球を上げる。
  steps:
    - 練習役はキッチンライン付近で構えて待つ
    - 上がった球を、逆サイドの外側へクロスのスマッシュで打ち込む
    - 球出し役は次の球を出して続ける
    - 一定時間で球出し役と練習役を交代する
  points:
    - 横向きになり、利き手と反対の手で球を指す
    - 打点は頭の前の高いところ
    - 逆サイドの外側（キッチンラインとトランの間）をねらう。サイドラインぎりぎりはアウトしやすいので、少し内側にする
  diagram:
    players:
      - { id: A, at: far-left-tran, role: feed }
      - { id: B, at: near-left-kitchen, role: practice }
    shots:
      - { from: A, to: B, type: lob, n: 1, afterBounce: true }
      - { from: B, to: far-rightOuter-kitchenTran, type: smash, n: 2 }
  builderDefault:
    min: 2
    sets: 5
---
