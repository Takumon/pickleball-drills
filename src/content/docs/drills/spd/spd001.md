---
title: スピードアップ → リセット
description: 緩いディンクをスピードアップし、相手はそれをリセットしてディンクに戻す
sidebar:
  order: 1
drill:
  id: spd001
  category: spd
  subCategories: [rst, dnk]
  scene: ディンクの打ち合いから、どちらかが浮いた球をスピードアップして、キッチンライン付近の速い打ち合い（ファイヤーファイト）が始まる。一瞬で決着がつく。
  purpose: スピードアップされた直後の速い球に遅れずに反応し、打ち負けずに返し続ける。
  focus: スピードアップで攻める側と、リセットでしのいでディンクの打ち合いに戻す側を、交互に打つ。
  setup: 2人1組でストレート（正面）に向かい合い、2人ともキッチンライン付近に立つ。1面で2組同時にできる。
  feed: 片方が緩いディンクを出して始める。
  steps:
    - Aが緩いディンクを出す
    - Bがスピードアップする
    - Aがリセットして、Bのキッチンに落とす
    - そのままディンクを1往復してから、Bがまたスピードアップし、同じ流れを繰り返す
    - 一定時間でAとBの役割を交代する
  points:
    - スピードアップは打てる高さに浮いた球だけを選んで打つ
    - リセットは振らずに面を作り、勢いを殺してキッチンに落とす
    - 打ったらすぐ構え直す
  diagram:
    rally: true
    players:
      - { id: A, at: far-left-kitchen, role: practice }
      - { id: B, at: near-left-kitchen, role: practice }
    shots:
      # 球出し → スピードアップ → リセット → ディンク → ディンク → スピードアップ → リセット → ディンク（書き手と決めた流れ）。
      # 繰り返すときは新しい球の球出しから始め直す
      - { from: A, to: B, type: dink, n: 1, bounce: front, feed: true, afterBounce: true, label: 球出し }
      - { from: B, to: A, type: speedup, n: 2 }
      - { from: A, to: B, type: reset, n: 3, bounce: front }
      - { from: B, to: A, type: dink, n: 4, bounce: front }
      - { from: A, to: B, type: dink, n: 5, bounce: front }
      - { from: B, to: A, type: speedup, n: 6 }
      - { from: A, to: B, type: reset, n: 7, bounce: front }
      - { from: B, to: A, type: dink, n: 8, bounce: front }
  variants:
    - key: fh
      default: true
      name: フォア
      note: フォアでスピードアップ
    - key: bh
      name: バック
      note: バックでスピードアップ
  builderDefault:
    min: 2
    sets: 5
