---
title: スピードアップ → リセット
description: 緩いディンクをスピードアップし、相手はそれをリセットしてディンクに戻す
sidebar:
  order: 1
drill:
  id: spd001
  category: spd
  purpose: ディンクの打ち合いでは浮いた球をスピードアップして攻めることも、スピードアップされた球をリセットしてしのぐことも必要になる。両方を交互に打つのは、攻めどきを逃さず、攻められても柔らかくディンクの打ち合いに戻して、相手に続けて攻めさせないため。
  setup: 2人1組でストレート（正面）に向かい合い、2人ともキッチンライン付近に立つ。1面で2組同時にできる。
  feed: 片方が緩いディンクを出して始める。
  steps:
    - Aが緩いディンクを出す
    - Bがスピードアップする
    - Aがリセットして、Bのキッチンに落とす
    - そのままディンクに戻り、同じ流れを繰り返す
    - 一定時間でAとBの役割を交代する
  points:
    - スピードアップは打てる高さに浮いた球だけを選んで打つ
    - リセットは振らずに面を作り、勢いを殺してキッチンに落とす
    - 打ったらすぐ構え直す
  diagram:
    players:
      - { id: A, x: 5, y: 14, role: practice }
      - { id: B, x: 5, y: 30, role: practice }
    shots:
      - { from: A, to: B, type: dink, curve: 0.25, n: 1, bounce: [5.8, 26.5] }
      - { from: B, to: A, type: speedup, curve: 0.12, n: 2 }
      - { from: A, to: [7, 26], type: reset, curve: -0.3, n: 3 }
  variants:
    - key: fh
      name: フォアでスピードアップ
      note: Bはフォアハンドでスピードアップする。
    - key: bh
      name: バックでスピードアップ
      note: Bはバックハンドでスピードアップする。
  builderDefault:
    min: 2
    sets: 5
  related:
    - spd002
    - rst008
---
