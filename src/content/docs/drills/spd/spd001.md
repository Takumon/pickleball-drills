---
title: スピードアップ → リセット
description: 緩いディンクをスピードアップし、相手はそれをリセットしてディンクに戻す
sidebar:
  order: 1
drill:
  id: spd001
  category: spd
  scene: ディンクの打ち合いでは、浮いた球をスピードアップして攻めることも、スピードアップされた球をリセットしてしのぐことも必要になる。
  purpose: 攻めどきを逃さず、攻められても柔らかくディンクの打ち合いに戻して、相手に続けて攻めさせない。
  setup: 2人1組でストレート（正面）に向かい合い、2人ともキッチンライン付近に立つ。1面で2組同時にできる。
  feed: 片方が緩いディンクを出して始める。
  steps:
    - Aが緩いディンクを出す
    - Bがスピードアップする
    - Aがリセットして、Bのキッチンに落とす
    - そのままディンクに戻り、同じ流れを繰り返す
    - 一定時間でAとBの役割を交代する
  points:
    - スピードアップは打てる高さに浮いた球だけを選んで打つ
    - リセットは振らずに面を作り、勢いを殺してキッチンに落とす
    - 打ったらすぐ構え直す
  diagram:
    players:
      - { id: A, at: far-left-kitchen, role: practice }
      - { id: B, at: near-left-kitchen, role: practice }
    shots:
      - { from: A, to: B, type: dink, n: 1, bounce: front }
      - { from: B, to: A, type: speedup, n: 2 }
      - { from: A, to: [7, 26], type: reset, n: 3 }
  variants:
    - key: fh
      name: フォアでスピードアップ
      note: Bはフォアハンドでスピードアップする。
    - key: bh
      name: バックでスピードアップ
      note: Bはバックハンドでスピードアップする。
  builderDefault:
    min: 2
    sets: 5
---
