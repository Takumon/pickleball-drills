---
title: スピードアップ → カウンター → リセット
description: スピードアップをカウンターで返し、そのあとリセットしてディンクに戻す
sidebar:
  order: 2
drill:
  id: spd002
  category: spd
  subCategories: [rst, vly]
  scene: ディンクの打ち合いから、どちらかが浮いた球をスピードアップして、キッチンライン付近の速い打ち合い（ファイヤーファイト）が始まる。一瞬で決着がつく。
  purpose: スピードアップされた直後の速い球に遅れずに反応し、打ち負けずに返し続ける。
  focus: スピードアップをカウンターで打ち返し、最後はリセットでディンクの打ち合いに戻す。
  setup: 2人1組でストレート（正面）に向かい合い、2人ともキッチンライン付近に立つ。1面で2組同時にできる。
  feed: 片方が緩いディンクを出して始める。
  steps:
    - Aが緩いディンクを出す
    - Bがスピードアップする
    - Aがカウンターで返す
    - Bがリセットして、Aのキッチンに落とす
    - Aがディンクで返し、Bがまたスピードアップして、同じ流れを繰り返す
    - 一定時間でAとBの役割を交代する
  points:
    - カウンターは小さく振り、パドルを体の前で使う
    - リセットは振らずに面を作り、勢いを殺してキッチンに落とす
    - 打ったらすぐ構え直す
  diagram:
    rally: true
    players:
      - { id: A, at: far-left-kitchen, role: practice }
      - { id: B, at: near-left-kitchen, role: practice }
    shots:
      # 球出し → スピードアップ → カウンター → リセット → ディンク → スピードアップ → カウンター → リセット（書き手と決めた流れ）。
      # 繰り返すときは新しい球の球出しから始め直す
      - { from: A, to: B, type: dink, n: 1, bounce: front, feed: true, afterBounce: true, label: 球出し }
      - { from: B, to: A, type: speedup, n: 2 }
      - { from: A, to: B, type: punch, n: 3 }
      - { from: B, to: A, type: reset, n: 4, bounce: front }
      - { from: A, to: B, type: dink, n: 5, bounce: front }
      - { from: B, to: A, type: speedup, n: 6 }
      - { from: A, to: B, type: punch, n: 7 }
      - { from: B, to: A, type: reset, n: 8, bounce: front }
  variants:
    - key: fh
      default: true
      name: フォア
      note: フォアでスピードアップ
    - key: bh
      name: バック
      note: バックでスピードアップ
  builderDefault:
    min: 2
    sets: 5
