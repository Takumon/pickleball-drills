---
title: スピードアップ → カウンター → リセット
description: スピードアップをカウンターで返し、そのあとリセットしてディンクに戻す
drill:
  id: spd002
  category: spd
  purpose: スピードアップされた球をカウンターで返し、打ち合いからリセットでディンクに戻す流れを練習する。
  setup: 2人1組でストレート（正面）に向かい合い、2人ともキッチンライン付近に立つ。1面で2組同時にできる。
  feed: 片方が緩いディンクを出して始める。
  steps:
    - Aが緩いディンクを出す
    - Bがスピードアップする
    - Aがカウンターで返す
    - Bがリセットして、Aのキッチンに落とす
    - そのままディンクに戻り、同じ流れを繰り返す
    - 一定時間でAとBの役割を交代する
  points:
    - カウンターは小さく振り、パドルを体の前で使う
    - リセットは振らずに面を作り、勢いを殺してキッチンに落とす
    - 打ったらすぐ構え直す
  diagram:
    players:
      - { id: A, x: 5, y: 14, role: practice }
      - { id: B, x: 5, y: 30, role: practice }
    shots:
      - { from: A, to: B, type: dink, curve: 0.3, n: 1, bounce: [6, 26.5] }
      - { from: B, to: A, type: speedup, n: 2 }
      - { from: A, to: B, type: volley, curve: -0.35, n: 3 }
      - { from: B, to: [9, 18.5], type: reset, n: 4 }
  variants:
    - key: fh
      name: フォアでスピードアップ
      note: Bはフォアハンドでスピードアップする。
    - key: bh
      name: バックでスピードアップ
      note: Bはバックハンドでスピードアップする。
  time:
    min: 2
    sets: 5
  related:
    - spd001
    - spd005
---
