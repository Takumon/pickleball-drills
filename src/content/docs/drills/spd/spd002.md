---
title: スピードアップ → カウンター → リセット
description: スピードアップをカウンターで返し、そのあとリセットしてディンクに戻す
sidebar:
  order: 2
drill:
  id: spd002
  category: spd
  purpose: スピードアップされた球はカウンターで打ち返せれば、そのまま攻め返せる。カウンターからリセットまでを続けて打つのは、速い打ち合いで押し負けず、最後はディンクの打ち合いに戻すため。
  setup: 2人1組でストレート（正面）に向かい合い、2人ともキッチンライン付近に立つ。1面で2組同時にできる。
  feed: 片方が緩いディンクを出して始める。
  steps:
    - Aが緩いディンクを出す
    - Bがスピードアップする
    - Aがカウンターで返す
    - Bがリセットして、Aのキッチンに落とす
    - そのままディンクに戻り、同じ流れを繰り返す
    - 一定時間でAとBの役割を交代する
  points:
    - カウンターは小さく振り、パドルを体の前で使う
    - リセットは振らずに面を作り、勢いを殺してキッチンに落とす
    - 打ったらすぐ構え直す
  diagram:
    players:
      - { id: A, at: far-left-kitchen, role: practice }
      - { id: B, at: near-left-kitchen, role: practice }
    shots:
      - { from: A, to: B, type: dink, n: 1, bounce: front }
      - { from: B, to: A, type: speedup, n: 2 }
      - { from: A, to: B, type: punch, n: 3 }
      - { from: B, to: [9, 18.5], type: reset, n: 4 }
  variants:
    - key: fh
      name: フォアでスピードアップ
      note: Bはフォアハンドでスピードアップする。
    - key: bh
      name: バックでスピードアップ
      note: Bはバックハンドでスピードアップする。
  builderDefault:
    min: 2
    sets: 5
  related:
    - spd001
    - spd005
---
