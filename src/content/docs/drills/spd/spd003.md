---
title: 2人でファイヤーファイト
description: キッチンライン付近で、2人で速いボレーの打ち合いを続ける
drill:
  id: spd003
  category: spd
  purpose: キッチンライン付近での速い打ち合い（ファイヤーファイト）に慣れる。
  setup: 2人1組でストレート（正面）に向かい合い、2人ともキッチンライン付近に立つ。1面で2組同時にできる。
  feed: どちらかが速めのボレーを出して始める。
  steps:
    - 2人ともパドルを体の前に構える
    - 速いボレーの打ち合いを続ける
    - ミスしたら、すぐ球を出し直して続ける
  points:
    - パドルを体の前、胸の高さに構えておく
    - 大きく振らず、小さく速く返す
    - 返球は相手の利き手側の肩より下を狙う
  diagram:
    players:
      - { id: A, x: 5, y: 14, role: practice }
      - { id: B, x: 5, y: 30, role: practice }
    shots:
      - { from: A, to: B, type: volley, curve: 0.2, n: 1 }
      - { from: B, to: A, type: volley, curve: 0.2, n: 2 }
  time:
    min: 2
    sets: 5
  related:
    - spd004
    - spd005
    - vly004
