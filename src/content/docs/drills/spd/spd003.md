---
title: 2人でファイヤーファイト
description: キッチンライン付近で、2人で速いボレーの打ち合いを続ける
sidebar:
  order: 3
drill:
  id: spd003
  category: spd
  scene: ディンクの打ち合いから、どちらかが浮いた球をスピードアップして、キッチンライン付近の速い打ち合い（ファイヤーファイト）が始まる。一瞬で決着がつく。
  purpose: スピードアップされた直後の速い球に遅れずに反応し、打ち負けずに返し続ける。
  focus: 最初から速いボレーで打ち合い、速い球に体を慣らして、浮いた球を見逃さずに決める。
  setup: 2人1組でストレート（正面）に向かい合い、2人ともキッチンライン付近に立つ。1面で2組同時にできる。
  feed: どちらかが速めのボレーを出して始める。
  steps:
    - 2人ともパドルを体の前に構える
    - 速いボレーの打ち合いを続ける
    - ミスしたら、すぐ球を出し直して続ける
  points:
    - パドルを体の前、胸の高さに構えておく
    - 大きく振らず、小さく速く返す
    - 返球は相手の利き手側の肩より下を狙う
  diagram:
    players:

      - { id: B, at: near-left-kitchen, role: practice }
    shots:
      - { from: A, to: B, type: punch, n: 1 }
      - { from: B, to: A, type: punch, n: 2 }
  builderDefault:
    min: 2
    sets: 5
