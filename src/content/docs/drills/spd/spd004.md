title: 4人でファイヤーファイト
description: 2対2で、キッチンライン付近の速いボレーの打ち合いを続ける
sidebar:
  order: 4
drill:
  id: spd004
  category: spd
  purpose: 試合のファイヤーファイトは2対2で、誰から速い球が来るか分からない中で起きる。4人で打ち合うのは、どこから来る速い球にも遅れずに反応し、打ち負けずに返し続けるため。
  setup: 4人で2対2になり、全員がキッチンライン付近に立つ。1面を1組で使う。
  feed: どちらかのペアが緩いディンクを出し、相手ペアのどちらかがスピードアップして始める。
  steps:
    - ディンクからスピードアップして打ち合いを始める
    - 4人で速いボレーの打ち合いを続ける
    - 決まるかミスするまで続け、ディンクから再開する
  points:
    - パドルを体の前、胸の高さに構えておく
    - 大きく振らず、小さく速く返す
    - 真ん中の球はどちらが取るか、ペアで声をかけて決める
  diagram:
    players:
      - { id: A, x: 5, y: 14, role: practice }
      - { id: C, x: 15, y: 14, role: practice }
      - { id: B, x: 5, y: 30, role: practice }
      - { id: D, x: 15, y: 30, role: practice }
    shots:
      - { from: A, to: B, type: dink, curve: 0.1, n: 1, bounce: [5.4, 26.5] }
      - { from: B, to: C, type: speedup, n: 2 }
      - { from: C, to: D, type: volley, curve: 0.1, n: 3 }
      - { from: D, to: A, type: volley, n: 4 }
  time:
    min: 2
    sets: 5
  related:
    - spd003
    - vly005
