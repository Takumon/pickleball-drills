drill:
  id: spd004
  category: spd
  scene: ディンクの打ち合いから、どちらかが浮いた球をスピードアップして、キッチンライン付近の速い打ち合い（ファイヤーファイト）が始まる。一瞬で決着がつく。
  purpose: スピードアップされた直後の速い球に遅れずに反応し、打ち負けずに返し続ける。
  focus: 2対2で、誰から速い球が来るか分からない中で反応する。
  setup: 4人で2対2になり、全員がキッチンライン付近に立つ。1面を1組で使う。
  feed: どちらかのペアが緩いディンクを出し、相手ペアのどちらかがスピードアップして始める。
  steps:
    - ディンクからスピードアップして打ち合いを始める
    - 4人で速いボレーの打ち合いを続ける
    - 決まるかミスするまで続け、ディンクから再開する
  points:
    - パドルを体の前、胸の高さに構えておく
    - 大きく振らず、小さく速く返す
    - 真ん中の球はどちらが取るか、ペアで声をかけて決める
  diagram:

      - { id: B, at: near-left-kitchen, role: practice }
      - { id: D, at: near-right-kitchen, role: practice }
    shots:
      - { from: A, to: B, type: dink, n: 1, bounce: front }
      - { from: B, to: C, type: speedup, n: 2 }
      - { from: C, to: D, type: punch, n: 3 }
      - { from: D, to: A, type: punch, n: 4 }
