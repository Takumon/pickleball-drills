---
title: スピードアップからのファイヤーファイト
description: ディンクからスピードアップし、そのまま速い打ち合いを続ける
sidebar:
  order: 5
drill:
  id: spd005
  category: spd
  purpose: 試合のファイヤーファイトは多くがディンクからのスピードアップで始まる。ディンクから始めて打ち合うのは、スピードアップされた直後の速い球に遅れずに反応し、打ち負けずに返し続けるため。
  setup: 2人1組でストレート（正面）に向かい合い、2人ともキッチンライン付近に立つ。1面で2組同時にできる。
  feed: 片方が緩いディンクを出して始める。
  steps:
    - Aが緩いディンクを出す
    - Bがスピードアップする
    - そのまま速いボレーの打ち合いを続ける
    - 決まるかミスするまで続け、ディンクから再開する
  points:
    - スピードアップされる前からパドルを体の前に構えておく
    - 大きく振らず、小さく速く返す
    - 打ち合いの中でも浮いた球を見逃さない
  diagram:
    players:
      - { id: A, x: 5, y: 14, role: practice }
      - { id: B, x: 5, y: 30, role: practice }
    shots:
      - { from: A, to: B, type: dink, curve: 0.3, n: 1, bounce: [6, 26.5] }
      - { from: B, to: A, type: speedup, curve: 0.3, n: 2 }
      - { from: A, to: B, type: volley, curve: -0.05, n: 3 }
  time:
    min: 2
    sets: 5
  related:
    - spd002
    - spd003
