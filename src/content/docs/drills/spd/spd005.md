---
title: スピードアップからのファイヤーファイト
description: ディンクからスピードアップし、そのまま速い打ち合いを続ける
sidebar:
  order: 5
drill:
  id: spd005
  category: spd
  scene: ディンクの打ち合いから、どちらかが浮いた球をスピードアップして、キッチンライン付近の速い打ち合い（ファイヤーファイト）が始まる。一瞬で決着がつく。
  purpose: スピードアップされた直後の速い球に遅れずに反応し、打ち負けずに返し続ける。このドリルではディンクから始め、試合と同じ流れで、スピードアップされた直後の球に反応する。
  setup: 2人1組でストレート（正面）に向かい合い、2人ともキッチンライン付近に立つ。1面で2組同時にできる。
  feed: 片方が緩いディンクを出して始める。
  steps:
    - Aが緩いディンクを出す
    - Bがスピードアップする
    - そのまま速いボレーの打ち合いを続ける
    - 決まるかミスするまで続け、ディンクから再開する
  points:
    - スピードアップされる前からパドルを体の前に構えておく
    - 大きく振らず、小さく速く返す
    - 打ち合いの中でも浮いた球を見逃さない
  diagram:
    players:
      - { id: A, at: far-left-kitchen, role: practice }
      - { id: B, at: near-left-kitchen, role: practice }
    shots:
      - { from: A, to: B, type: dink, n: 1, bounce: front }
      - { from: B, to: A, type: speedup, n: 2 }
      - { from: A, to: B, type: punch, n: 3 }
  builderDefault:
    min: 2
    sets: 5
